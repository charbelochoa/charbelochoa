## Español

Derivacion exacta de Jacobianos inversos para softmax(QK^T / sqrt(d_k)) y LayerNorm en NumPy puro antes de escalar arquitecturas Transformer.

Implementar retropropagacion manual sin autograd revela por que el factor 1/sqrt(d_k) y la posicion Pre-LayerNorm gobiernan la salud del gradiente. Sin escalamiento de varianza, el Jacobiano J_softmax = diag(p) - p p^T colapsa en regiones saturadas.

Colocar LayerNorm en la entrada residual preserva una autopista identidad desde la perdida final hasta los embeddings iniciales.

## English

Deriving exact backward Jacobians for softmax(QK^T / sqrt(d_k)) and LayerNorm in raw NumPy before scaling up to PyTorch Transformer stacks.

Implementing backpropagation manually without autograd exposes why 1/sqrt(d_k) and Pre-LayerNorm placement govern gradient health. Without variance scaling, dot products push softmax into saturated tails where the Jacobian J_softmax = diag(p) - p p^T vanishes.

Placing LayerNorm on the residual branch input preserves an identity highway from the final cross-entropy loss directly back to token embeddings at step 0, eliminating warmup instability.

## 中文

在扩展至 PyTorch 训练栈之前，使用纯 NumPy 推导注意力机制与 LayerNorm 的精确反向传播雅可比矩阵。

脱离自动求导手写反向传播，能够直观揭示 1/sqrt(d_k) 与 Pre-LayerNorm 对梯度稳定性的决定作用：未缩放点积会使 softmax 雅可比矩阵迅速饱和退化。

将归一化置于残差分支输入端可保留从损失函数直达底层词嵌入的恒等梯度通路。

## Ecuación

```text
dL/dS = P * ( dL/dP - rowsum(dL/dP * P) )   where   S = (Q K^T) / sqrt(d_k),  P = softmax(S)
```

## Código

```python
scale = 1.0 / np.sqrt(d_k)
dP = dOut @ V.swapaxes(-1, -2)
dS = P * (dP - np.sum(dP * P, axis=-1, keepdims=True))
dQ = (dS @ K) * scale
dK = (dS.swapaxes(-1, -2) @ Q) * scale
```
